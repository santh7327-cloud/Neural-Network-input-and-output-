HOW IT WORKS

A network learns by adjusting its connections.

This demo trains a small neural network on XOR: the output is 1 when the two inputs differ, and 0 when they match.

  • Green connections carry positive weights; coral connections carry negative weights.
  • The heatmap shows the network’s prediction for every input pair.
  • The learning curve tracks prediction error as training progresses.
